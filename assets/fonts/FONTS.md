# Fonts used in this profile

Both fonts are embedded as base64 WOFF2 inside the SVG files in `assets/`, so they render on GitHub
without any external requests. Both are licensed under the SIL Open Font License 1.1, which allows use,
embedding and redistribution (the font files are not sold on their own).

| Font | Role | Copyright | License text |
|------|------|-----------|--------------|
| Anton | Display headlines | Copyright 2020 The Anton Project Authors (https://github.com/googlefonts/AntonFont.git) | [LICENSE-Anton-OFL.txt](LICENSE-Anton-OFL.txt) |
| JetBrains Mono (Regular, Bold) | Body and code text | Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) | [LICENSE-JetBrainsMono-OFL.txt](LICENSE-JetBrainsMono-OFL.txt) |

The embedded WOFF2 data is the Latin subset distributed by Fontsource (`@fontsource/anton`,
`@fontsource/jetbrains-mono`), unchanged by this project.
